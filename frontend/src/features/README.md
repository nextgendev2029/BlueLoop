# Frontend Features (`src/features`)

This directory will organize feature-centric components, state slices, and domain views:
- `suppliers/`: Supplier registration forms, quality listing tables, and certificate viewers.
- `demands/`: Demand request wizards and tolerance threshold configuration.
- `allocations/`: Matching engine triggers, constraint visualizers, and allocation matrices.
- `deliveries/`: Dispatch log tables and custody acknowledgment actions.
- `impact/`: Freshwater savings charts and cost delta calculators.
